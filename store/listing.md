# Blur & Save on the Microsoft Store

## Description

Blur faces in photos before you share them. Open a JPG, PNG, or WebP photo and Blur & Save finds faces on your device. Review the result, draw a box over any face the app missed, and save a full-resolution PNG copy. You can also use solid black boxes to cover faces.

Blur & Save works offline. Your original photo stays untouched.

## Features

- Automatic face detection and blurring
- Draw or remove boxes in the preview
- Blur or solid black boxes
- Save a full-resolution PNG copy
- JPG, PNG, and WebP input

## Restricted capability justification

Blur & Save is a Windows desktop app. It uses the standard Windows file dialogs to open photos and save copies in user-selected locations. The package declares `runFullTrust` for its Win32 desktop entry point. It runs as the current user and does not request administrator access.

## Certification notes

No login, internet connection, camera, or microphone is needed. Open any local JPG, PNG, or WebP portrait to try automatic face blur. Review the preview, add a box by dragging over an area, and choose **Save a copy** to export a PNG.
